F1 Lamp — คู่มือการใช้งานและโครงสร้างระบบ

โครงสร้างโปรเจกต์แบ่งออกเป็น 2 ฝั่งชัดเจน (ไม่ปนกัน):
├── hardware/               (ฝั่งฮาร์ดแวร์ & เฟิร์มแวร์ ESP8266 ในบอร์ด)
│   └── F1_Lamp/
│       ├── F1_Lamp.ino     (โค้ดหลัก ESP8266 คลีนและมีคอมเมนต์ครบถ้วน)
│       ├── config.h        (ตั้งค่า Wi-Fi และรหัส OTA)
│       ├── effects.h       (สูตรคำนวณแสงไฟ 10 โหมด)
│       ├── cloud.h         (ระบบเชื่อมต่อคลาวด์ WebSocket TLS)
│       ├── relay_ca.h      (ใบรับรอง Root CA สำหรับเข้ารหัสความปลอดภัย)
│       └── web_assets.h    (เว็บสำรองแบบฝังใน Flash บอร์ด)
│
└── software/               (ฝั่งซอฟต์แวร์ คลาวด์ และเว็บแอปพลิเคชัน)
    ├── frontend/           (หน้าเว็บ Web App + 3D Simulator สำหรับขึ้น Cloudflare Pages)
    │   ├── index.html      (โครงสร้างหน้าเว็บ)
    │   ├── css/style.css   (ดีไซน์ธีม F1 Pit Wall)
    │   └── js/             (app.js, viewer.js, effects.js, model.json)
    │
    └── backend/            (Cloudflare Worker + MongoDB Atlas Relay)
        ├── wrangler.toml   (คอนฟิก Cloudflare Worker)
        ├── package.json    (ไลบรารีและคำสั่ง Deploy)
        └── src/
            ├── index.ts    (ระบบรับส่งคำสั่ง WebSocket & REST API)
            └── mongodb.ts  (บันทึกสถานะโคมไฟและ Preset ลง MongoDB)

====================================================================
ขั้นตอนที่ 1: ฝั่ง Hardware (ESP8266)
====================================================================
1. เปิด Arduino IDE แล้วเปิดไฟล์ hardware/F1_Lamp/F1_Lamp.ino
2. ติดตั้งไลบรารีผ่าน Library Manager:
   - Adafruit NeoPixel
   - ArduinoJson (เวอร์ชัน 7)
   - WebSockets by Markus Sattler
3. ตั้งค่า Wi-Fi และรหัสผ่าน OTA ในไฟล์ hardware/F1_Lamp/config.h
4. เลือกบอร์ด NodeMCU 1.0 (ESP-12E), Flash 4MB, FS 2MB (OTA)
5. เสียบสาย USB และกด Upload
   (ครั้งถัดไปสามารถอัปเดตแบบไร้สายผ่าน ArduinoOTA ได้)
6. ขาต่อ LED:
   - D1 (GPIO 5)  -> 4 ดวง
   - D2 (GPIO 4)  -> 6 ดวง
   - D5 (GPIO 14) -> 9 ดวง
   - ไฟเลี้ยงแนะนำ 5V นิ่งๆ (กระแสอย่างน้อย 2A) ร่วมกับกราวด์ร่วม (Common Ground)

====================================================================
ขั้นตอนที่ 2: ฝั่ง Software (Cloudflare Pages + Workers + MongoDB)
====================================================================
1. Deploy Backend (Cloudflare Workers):
   - เข้าโฟลเดอร์ software/backend/
   - รันคำสั่ง:
     npm install
     npx wrangler deploy
   - จะได้ URL ของ Worker เช่น https://f1-lamp-relay.<your-name>.workers.dev
   - (ออปชัน MongoDB): นำ Data API URL และ API Key จาก MongoDB Atlas มาใส่ใน wrangler secret:
     npx wrangler secret put MONGODB_DATA_API_KEY
     npx wrangler secret put MONGODB_DATA_API_URL

2. Deploy Frontend (Cloudflare Pages):
   - ลากโฟลเดอร์ software/frontend/ ไปวางบน Cloudflare Pages (Direct Upload)
   - หรือเชื่อมต่อผ่าน GitHub ชี้ Root Directory ไปที่ software/frontend/

====================================================================
ขั้นตอนที่ 3: จับคู่โคมไฟกับระบบคลาวด์ (ทำครั้งเดียว)
====================================================================
1. เปิดหน้าเว็บที่ Deploy บน Cloudflare Pages
2. กดปุ่ม "คัดลอกรหัสเชื่อมโคม"
3. สลับมือถือไปต่อ Wi-Fi บ้าน แล้วเปิด IP ของโคม (เช่น http://192.168.1.104/)
4. นำรหัสไปวางในช่อง "จับคู่ควบคุมนอกบ้าน" แล้วกดบันทึก
5. โคมจะบันทึกรหัสลง LittleFS ภายในตัว จากนั้นคุณสามารถใช้เน็ตมือถือ 4G/5G จากที่ไหนก็ได้สั่งงานโคมไฟได้ทันที!
