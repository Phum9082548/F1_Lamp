F1 Lamp — วิธีใช้

1. แตก ZIP แล้วเปิด F1_Lamp/F1_Lamp.ino ใน Arduino IDE
2. ติดตั้ง Adafruit NeoPixel, ArduinoJson 7 และ WebSockets by Markus Sattler
   แล้วเลือกบอร์ด ESP8266 ที่ใช้อยู่
   โค้ดทดสอบคอมไพล์ด้วย NodeMCU 1.0 (ESP-12E), Flash 4MB, FS 2MB (OTA)
3. config.h ใส่ Wi-Fi และรหัส OTA ตามที่ให้มาแล้ว แก้ได้ในไฟล์นี้
4. เลือกพอร์ต OTA ของบอร์ด แล้วกด Upload ใช้รหัส OTA ที่อยู่ในบอร์ดปัจจุบัน
   ถ้ารหัสไม่ผ่าน ให้เลือก COM แล้วอัปผ่าน USB หนึ่งครั้ง
5. เปิด http://192.168.1.104/ จากมือถือหรือคอมใน Wi-Fi เดียวกัน
   หากเข้าไม่ได้ ดู IP ปัจจุบันจาก Serial Monitor 115200
6. เมื่อขึ้น “เชื่อมต่อโคมแล้ว” จึงควบคุมไฟจริงได้

ไม่ต้องอัปไฟล์เว็บเพิ่ม: หน้าเว็บและโมเดลรวมอยู่ใน web_assets.h แล้ว
รุ่น 3: สีแดงล้วน 10 โหมด พร้อมเฟดเข้า/ออกและเปลี่ยนโหมด 700 มิลลิวินาที
ไฟค้าง / เร่งเครื่อง / ดาวหาง / หายใจ / คลื่น / สแกน / แผ่กลาง / หัวใจ / ประกาย / สลับโซน
แตก ZIP ทั้งหมดก่อนเปิด .ino ต้องมี config.h, effects.h และ web_assets.h อยู่ข้างกัน
D1 = 4 ดวง / D2 = 6 ดวง / D5 = 9 ดวง
OTA ยังคงอยู่และใช้รหัสใน config.h หลังอัปสำเร็จ
ต้องใช้ไฟเลี้ยงเสถียร: แหล่งจ่ายประมาณ 3.8V ที่คุยไว้ต้องแก้ก่อน
รุ่นนี้เริ่มด้วยเอฟเฟกต์เร่งเครื่องแล้วติดค้าง การตั้งค่าในโคมไม่เก็บข้ามการปิดไฟ

ควบคุมจากนอกบ้าน / 4G / 5G:
1. จับคู่ครั้งแรกขณะอยู่บ้าน: เปิดเว็บออนไลน์ และลงชื่อเข้าใช้บัญชีเจ้าของเว็บ
   https://f1-lamp-pit-control.rockybarge16.chatgpt.site/
2. กด “คัดลอกรหัสเชื่อมโคม” เก็บรหัสนี้เป็นส่วนตัว
3. ต่อมือถือเข้า Wi-Fi บ้าน เปิด IP ของโคม วางรหัสในช่อง “จับคู่ควบคุมนอกบ้าน” แล้วบันทึก
4. รอขึ้น “โคมเชื่อมระบบนอกบ้านแล้ว” จากนั้นใช้เน็ตมือถือเปิดเว็บออนไลน์เดิมได้
5. โคมต้องมีไฟเลี้ยงและต่ออินเทอร์เน็ตบ้านอยู่เสมอ ไม่ต้องเปิดพอร์ตเราเตอร์
จับคู่ครั้งเดียว โคมจำไว้ใน LittleFS การอัป OTA แบบไม่ล้างแฟลชจะเก็บการจับคู่ไว้
ไฟล์ ZIP ไม่มีรหัสระบบนอกบ้าน ต้องจับคู่ตามขั้นตอนข้างบน

F1-Lamp-Control.html เปิดดูโมเดลและจำลองไฟได้โดยตรง
ควบคุมในบ้านให้เข้า IP บอร์ด ควบคุมจากนอกบ้านให้เข้าเว็บออนไลน์
ไฟล์ 3MF เดิมเป็นชิ้นงานบนถาดพิมพ์ โมเดลนี้จัดประกอบเพื่อแสดงผลจากเมชเดิมครบ 8 ชิ้น
ตำแหน่งช่อง LED ในภาพเป็นภาพประกอบ อาจต่างจากการเดินสายจริง

ตรวจคอมไพล์และทดสอบหน้าเว็บแล้ว แต่ยังไม่ได้อัปหรือทดสอบกับโคมจริง
